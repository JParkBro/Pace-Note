# 제품 · 화면 정의

런닝앱의 기능 범위, 기록 · 계산 규칙, 화면 목록과 동작을 정의합니다. 디자인 시안(Stitch) 작업과 개발 모두 이 문서를 기준으로 합니다. 화면 배치는 시안 [design/README.md](design/README.md), 위치 추적 구현은 [tracking.md](tracking.md)를 함께 봅니다.

## 1. 제품 개요

| 항목 | 내용 |
|---|---|
| 한 줄 소개 | 매일 조금씩, 꾸준히 — 지도 없이 가볍게 쓰는 러닝 기록 |
| 대상 | 입문~중급 러너 (한국 사용자) |
| 플랫폼 | Android (iOS는 이후 검토) |
| 앱 표시 이름 | 런닝 (가칭) |
| 기본 원칙 | 혼자 쓰는 앱. 기록은 기기가 원본, 로그인은 백업을 위한 선택 |

### 사용 모드

| 모드 | 설명 |
|---|---|
| 게스트 | 로그인 없이 모든 기능 사용. 기록은 기기에만 |
| 로그인 (Google) | 게스트 기능 + 기록 · 목표 · 내 정보 백업과 복원 (다른 기기 · 재설치) |

- 게스트로 쓰다가 로그인하면 "이 기기의 기록 N개를 계정에 백업할까요?"를 묻고, 기본은 백업합니다.
- 이미 백업이 있는 계정으로 로그인하면 서버 기록과 기기 기록을 합칩니다 (같은 id는 `updatedAt`이 최신인 쪽).
- 로그아웃해도 기기의 기록은 지우지 않습니다. 화면에는 게스트 기록만 보이고, 같은 계정으로 다시 로그인하면 그 계정 기록이 다시 보입니다.

## 2. 기록 규칙

계산식 · 임계값의 근거와 구현은 [tracking.md](tracking.md) 4~5장이 원문입니다. 이 장은 사용자에게 보이는 동작만 정의합니다.

### 2-1. 기록의 상태

| 상태 | 의미 |
|---|---|
| `ACTIVE` | 기록 중 (추적 서비스 실행 중) |
| `PAUSED` | 일시정지 (사용자 또는 자동) |
| `FINISHED` | 저장된 기록 |
| `DISCARDED` | 사용자가 버림 (화면에 보이지 않고, 정리 작업이 지움) |

### 2-2. 표시 수치

| 수치 | 규칙 | 표기 |
|---|---|---|
| 거리 | 필터를 통과한 점 사이 거리의 합. 일시정지 구간은 넣지 않음 | `5.21 km` (소수 둘째 자리, 내림) |
| 시간 | **운동 시간** = 일시정지를 뺀 시간. 기록 상세에는 경과 시간(시작~종료)도 작게 표시 | `30:12`, 1시간 이상 `1:12:40` |
| 평균 페이스 | 운동 시간 ÷ 거리 | `5′48″` (/km) |
| 현재 페이스 | 최근 약 200m(또는 30초) 구간 평균. 순간값을 쓰지 않음 | `5′55″`, 정지 · 데이터 부족 시 `–′––″` |
| 구간 (스플릿) | 1km마다 걸린 운동 시간. 마지막 남은 구간은 실제 거리와 환산 페이스 | `1 km 5′52″` … `0.21 km 6′16″` |
| 칼로리 | 체중(kg) × 거리(km) × 1.036. 체중을 입력하지 않으면 표시하지 않음 | `351 kcal` |

- 거리 단위를 mile로 바꾸면 거리 · 페이스 · 스플릿이 모두 mile 기준이 됩니다. 저장은 항상 미터 · 밀리초입니다.
- 페이스가 20′00″/km보다 느리면 "걷기 속도"로 보고 현재 페이스를 `–′––″`로 표시합니다.

### 2-3. 자동 일시정지

- 설정에서 켠 경우(기본 켬), 일정 시간 거의 움직이지 않으면 자동으로 일시정지하고 다시 움직이면 재개합니다.
- 자동 일시정지 중에는 P4가 아니라 P3에 "멈춤 감지됨" 표시만 띄우고, 음성 안내로 "일시정지" · "다시 시작"을 알립니다.
- 사용자가 직접 누른 일시정지는 자동으로 재개하지 않습니다.

### 2-4. 저장 기준

- 거리 100m 미만이면 종료 확인(P5)에서 "저장하지 않고 마치기"가 기본 버튼이 됩니다.
- 운동 시간 10분 미만의 짧은 기록도 저장할 수 있습니다 (입문자 동기 유지).
- GPS가 한 번도 잡히지 않은 기록(신호 없이 시작 후 점 0개)은 거리 0으로 저장되며, 시간만 기록됩니다.

### 2-5. 음성 안내

| 항목 | 기본값 | 선택지 |
|---|---|---|
| 음성 안내 | 켬 | 켬 / 끔 |
| 간격 | 1km | 0.5km · 1km · 2km · 5분 · 10분 |
| 항목 | 거리 · 평균 페이스 | 거리 · 시간 · 평균 페이스 · 구간 페이스 중 복수 선택 |

예: "1킬로미터. 5분 52초. 평균 페이스 5분 52초." 음악은 잠시 줄였다가(덕킹) 안내 후 되돌립니다.

## 3. 목표 규칙

| 항목 | 규칙 |
|---|---|
| 종류 | 주간 거리(km) 또는 주간 횟수(회) 중 하나 |
| 한 주 | 월요일 00:00 ~ 일요일 23:59, 기기 시간대 기준 |
| 포함 기준 | 기록의 **시작 시각**이 속한 주 |
| 진행률 | 이번 주 합계 ÷ 목표. 100%를 넘어도 그대로 표시 (`17.2 / 15 km`) |
| 기본 추천 | 거리 15km 또는 주 3회. 기록이 4주 이상 쌓이면 "최근 4주 평균"을 함께 보여줌 |
| 변경 | 언제든 변경 가능. 변경은 이번 주부터 적용하고 지난 주 달성 여부는 바꾸지 않음 |

지난 주 달성 여부는 저장하지 않고 기록과 "그 주의 목표값"으로 계산합니다. 그래서 목표를 바꿀 때 `goal_history`(적용 시작 주, 종류, 값)를 남깁니다 (v2 연속 기록 기능의 기반).

## 4. 화면 구조

### 4-1. 내비게이션

```
[첫 실행]  O0 시작 → O1 약관 동의 → O2 기본 정보 → O3 첫 목표 → H1 홈

[하단 탭]  H1 홈 │ 기록 (R1 목록 ⇄ R2 통계) │ M1 내 정보
           R1 → R3 기록 상세 → R4 편집 / P7 공유 카드
           M1 → M2 ~ M10

[러닝]     H1 [달리기 시작] → P1 준비 → P2 카운트다운 → P3 러닝 중 ⇄ P3-L 잠금
           P3 → P4 일시정지 → P5 종료 확인 → P6 결과 → P7 공유 카드 → H1
           앱 시작 시 진행 중 기록이 있으면 P8 복구
```

- 하단 탭은 탭마다 백스택을 따로 둡니다 (ANDROID_ARCHITECTURE 5-3).
- 러닝 흐름(P1~P6)은 탭 밖 전체 화면이며, P3 · P4에서는 뒤로 가기로 기록이 끝나지 않습니다 (뒤로 = 앱을 백그라운드로, 추적은 계속).
- P6에서 "완료"를 누르면 러닝 흐름 전체를 백스택에서 지우고 홈으로 갑니다.

## 5. 주요 화면 동작

### 5-1. 홈 (H1)

- 상단: "이번 주"와 기간(`10.26 – 11.1`), 주간 목표 진행 링(목표가 없으면 이번 주 거리만 + "목표 정하기" 링크 → M2).
- 이번 주 요약 3개: 횟수 · 운동 시간 합계 · 평균 페이스.
- **"달리기 시작"이 화면의 주인공**입니다. 누르면 P1부터.
- 최근 기록 2개(흰 선 썸네일). 누르면 R3. 기록이 없으면 "첫 러닝을 시작해 보세요" 빈 상태.
- 목표를 이번 주에 처음 달성하면 링 아래에 "이번 주 목표 달성!" 뱃지(success).

### 5-2. 준비 (P1)

| 순서 | 조건 | 내용 |
|---|---|---|
| P1-a | 정밀 위치 권한이 없을 때 | 이유 설명 → 시스템 권한 요청 (정밀 · 대략 함께). 대략만 허용하면 "정확한 거리를 재려면 '정확한 위치'가 필요해요" 안내 후 다시 요청 · 설정 이동. Android 13+는 같은 흐름에서 알림 권한도 요청 (거부해도 기록은 가능, 진행 알림만 안 보임) |
| P1-b | 첫 러닝이고, 배터리 최적화 대상일 때 (1회) | 배터리 최적화 해제 안내 → 시스템 설정 목록 열기. "다음에 하기" 가능. M3에서 다시 보기 |
| P1-c | 항상 | GPS 신호 대기. 정확도가 기준(20m) 이내가 되면 "시작" 활성. "신호 없이 시작"도 가능 (점이 들어오면 그때부터 거리 계산) |

- 기기 위치 설정이 꺼져 있으면 P1-c에서 "위치가 꺼져 있어요" + 켜기 요청 (시스템 설정 대화상자).

### 5-3. 카운트다운 · 러닝 중 (P2 · P3)

- 카운트다운(기본 3초, 0 · 3 · 5 · 10초)이 끝나는 순간 추적 서비스가 기록을 시작합니다. 화면을 탭하면 바로 시작.
- P3: 거리(가장 크게) · 운동 시간 · 현재 페이스. 아래에 **지금까지의 경로가 실시간으로 늘어나는 흰 선** (현재 위치는 `route-start` 색 점).
- 잠금(P3-L): 오른쪽 위 자물쇠를 누르면 모든 버튼이 비활성되고 "길게 눌러 잠금 해제"만 남습니다.
- 화면 켜짐 유지는 설정(M3)에서 켠 경우만 (기본 끔).

### 5-4. 일시정지 · 종료 (P4 · P5)

- P4: "일시정지됨", 거리 · 운동 시간 · 평균 페이스, 경로. 재개(primary) / 종료(길게 누르기 1초).
- P5 바텀시트: "러닝을 마칠까요?" + 거리 · 시간. [저장하고 마치기] / [계속 달리기]. 100m 미만이면 [저장하지 않고 마치기]가 위로 오고 [저장하기]는 텍스트 버튼.

### 5-5. 결과 (P6)

- 상단 제목: 시작 날짜 · 시각, 오른쪽 "완료".
- 경로(크게) → 2×2 수치(거리 · 시간 · 평균 페이스 · 칼로리) → 이번 주 목표 기여("이번 주 목표 83% · 2.6km 남았어요", 진행바) → 구간 표 → 메모 입력 → [공유 카드 만들기].
- 결과는 P5에서 저장하는 순간 이미 저장되어 있습니다. P6의 메모는 입력이 멈추면 자동 저장.
- 로그인 상태이고 자동 백업이 켜져 있으면 저장 직후 백업 대기열에 들어갑니다.

### 5-6. 공유 카드 (P7)

| 항목 | 내용 |
|---|---|
| 크기 | 기본 · 사진: 1080×1350 (4:5) PNG. 투명: 1080×1080 투명 PNG (흰 선 + 수치만, 인스타 스토리 스티커용) |
| 배경 | 기본(`route-canvas`) · 사진(시스템 사진 선택기, 권한 없음, `image-scrim`) · 투명 |
| 표시 정보 | 거리 · 시간 · 페이스 · 날짜 중 선택 (기본: 거리 · 시간 · 페이스) |
| 표기 | 앱 이름은 카드 아래쪽 작은 글자 하나만. 지도 · 장소명 · 좌표 없음 |
| 동작 | [이미지 저장] → 사진 앱(`Pictures/런닝`), [공유] → 시스템 공유 시트 |

- 공유 카드는 앱 테마와 독립입니다 (theme-guide 5.11). 테마를 바꿔도 같은 카드가 나옵니다.

### 5-7. 기록 탭 (R1 · R2)

- R1: 월별 그룹, 월 헤더에 합계(거리 · 횟수). 항목: 흰 선 썸네일 · 거리 · 날짜(요일) · 시간 · 페이스. 무한 스크롤(Room 페이징).
- R2: `주 / 월` 칩 + 기간 이동(‹ ›).
  - 주: 요일별(월~일) 거리 막대 (`accent`), 합계 · 횟수 · 평균 페이스, 지난주 대비 문장.
  - 월: 주차별 막대, 같은 요약, 지난달 대비.
- 기록이 없으면 빈 상태 + "달리기 시작" 버튼.

### 5-8. 기록 상세 · 편집 (R3 · R4)

- R3: P6와 같은 구성(읽기 전용) + 페이스 그래프(km별 꺾은선, `accent`) + 경과 시간 · 시작/종료 시각. 오른쪽 위 ⋯ → 편집.
- R4: 제목(기본: "{요일} {아침 · 점심 · 저녁 · 밤} 러닝", 40자) · 메모(500자). 때는 시작 시각(기록의 시간대) 기준 아침 05:00 ~ 10:59 · 점심 11:00 ~ 16:59 · 저녁 17:00 ~ 20:59 · 밤 21:00 ~ 04:59 (자정을 넘긴 밤은 그 날짜의 요일). 제목을 비우면 저장하지 않고 기본 제목을 보여줍니다. 맨 아래 "이 기록 삭제" → 확인 다이얼로그 → soft delete 후 목록으로.

### 5-9. 진행 중 알림 (N1)

- 러닝 중 항상 표시(포그라운드 서비스). 제목: "러닝 기록 중", 시간은 시스템 크로노미터, 거리 · 페이스는 5초마다 갱신.
- 버튼: 일시정지 / 재개, 열기. 알림을 누르면 P3(또는 P4)로.
- 일시정지 중에는 크로노미터를 멈추고 "일시정지됨"을 표시합니다.

내 정보 (탭, M1)
├─ 요약 카드 (누적 거리 · 누적 러닝)

│                          로그인: 이메일 · 마지막 백업 → 계정(M10)

│   └─ 내 정보 수정 ────→ M4 (체중, 거리 단위)
├─ 앱 설정
│   ├─ 테마 ────────────→ M5 바텀시트 (4 테마 + 시스템 / 라이트 / 다크). 고르는 즉시 미리보기,
│   │                     [테마 적용하기]로 저장, 닫으면 원래대로 (데이즈와 같은 방식)
│   └─ 데이터 · 백업 ───→ M6 (자동 백업 토글, 지금 백업, 백업에서 복원, [기기의 모든 기록 삭제])
├─ 지원
│   ├─ 문의하기 (메일 앱, 앱 버전 · 기기 모델 자동 첨부)
│   └─ 앱 평가하기 (Play 인앱 리뷰)
├─ 정보

- **회원 탈퇴** (M10 맨 아래): 무엇이 지워지는지 안내(서버의 백업 기록 · 동의 기록 · 계정) + "기기의 기록도 지우기"(선택, 기본 끔) → "안내를 모두 확인했어요" → Google로 다시 로그인해 본인 확인 → 탈퇴. 탈퇴 후 게스트 상태로 홈.
- 정책 문서는 Firebase Hosting 페이지를 웹뷰로 엽니다 (`infra-and-billing-protection.md` 2-4).

## 8. 위젯

- 크기: 주간 목표 4×2(기본) · 2×2. 세부 규칙은 `widget/CLAUDE.md`.
- 4×2: "이번 주", `12.4 / 15 km`, 진행바, "달리기 시작" 버튼. 버튼은 P1(권한 · GPS 확인)부터, 나머지 영역은 홈.
- 2×2: 진행 링 + 이번 주 거리. 탭하면 홈.
- 목표가 없으면 이번 주 거리만 표시합니다.
- 테마 팔레트는 앱과 같고 기기 다크 모드를 따릅니다.
- 갱신: 기록 저장 · 삭제 · 복원, 목표 · 테마 변경, 매주 월요일 00:00, 시각 · 시간대 변경.
- 러닝 중 상태는 위젯에 표시하지 않습니다 (진행 중 알림이 담당).

## 11. 디자인 시안 작업 (Stitch)

프롬프트는 [stitch-prompts.md](stitch-prompts.md). 시안은 `docs/run/design/{화면 ID 소문자}/`(`screen.png`, `code.html`)에 있고, 화면별 경로는 [design/README.md](design/README.md)입니다. P1-b · P3-L · M4 · M8 · U1은 시안이 없으므로 5 · 7장 동작과 같은 묶음의 시안을 기준으로 구성합니다.

- 공통 컨텍스트에 테마 색(볼트 라임 다크)과 **"지도 금지, 경로는 흰 선만"**을 먼저 넣고 시작합니다.
- 모든 헤더 · 라벨은 한국어, 하위 화면에 프로필 아이콘 · 알림 벨 없음.
- 샘플 데이터는 9장 시나리오를 사용합니다.
- 시안에 들어 있어도 이 문서와 다른 것(지도, 소셜, 심박수, 배지 진열장 등)은 구현하지 않고, 받은 뒤 이 장에 "시안과 다른 부분" 표로 기록합니다.

### 시안과 다른 부분

`code.html`의 문구를 이 문서와 대조한 결과입니다. 아래 항목은 시안에 있어도 **구현하지 않고** 이 문서를 따릅니다.

| 화면 | 시안에 있는 것 | 처리 |
|---|---|---|
| O0 | "계속 진행함으로써 … 동의합니다" 문구, 슬로건 추가 | 동의는 O1에서만 받음. 문구 넣지 않음 |
| O1 | 상단 와이어프레임 썸네일, "STEP 01" 표시, 진행 점 | 넣지 않음 |
